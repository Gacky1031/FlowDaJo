# FlowDesk Tauri 0.4.0 — Global worksheet

Windows / macOS用フローサイトメトリー解析アプリ。Rust + Tauri / R flowCore。各OS用のRと必要なRパッケージを同梱し、追加のRインストールなしで利用できます。Windows版のみ固定版WebView2も同梱します。

## 起動

- このPC: `release/FlowDesk-Tauri-0.4.0/FlowDesk-Tauri.exe`
- 配布ZIP: `release/FlowDesk-Tauri-0.4.0-windows-x64-bundled.zip`
- インストーラー: `release/FlowDesk Tauri_0.4.0_x64-setup.exe`

ZIPはフォルダ全体をローカルドライブに展開してください。EXEだけの移動はできません。対象はWindows 10/11 x64。実機検証はWindows 11です。旧Python版と0.2.0・0.3.0・0.3.1の配布物は残しています。

## macOS版

macOS版はGitHub Actionsの **Build macOS installers** から生成されます。Intel Mac用 `FlowDesk-Tauri-macos-x64` とApple Silicon用 `FlowDesk-Tauri-macos-aarch64` のDMGを選び、DMGを開いて `FlowDesk Tauri.app` をApplicationsへドラッグしてください。RとflowCoreは.app内に同梱されます。

最初の配布物はApple Developer ID署名・公証を行っていないため、macOSの警告が出た場合はFinderでアプリをcontrolクリックして「開く」を選択してください。署名済み配布へ移行する場合は、CIにApple証明書と公証用のシークレットを設定します。
## ワークシート

- **4プロット固定を廃止。** 「＋ Plot」で追加、カード右上で複製・削除。ヘッダーのつまみをドラッグして移動、右下をドラッグしてサイズを変更できます。「グリッド整列」は最寄りの位置へ揃えます。隣のドロップダウンから行×列を指定して、シート全体または選択プロットを配置できます。
- ワークシートの空白部分をドラッグすると矩形で複数プロット・ウィジェットを選択できます。Shift/Ctrl/⌘を押しながらドラッグすると、選択項目に追加できます。
- 上部タブの「＋」でワークシートを追加。「⧉」でシート全体を複製し、ワークシートタブの右クリックメニューからシートと内容をまとめて削除できます。名前、全カードの位置・サイズ・軸・表示集団をプロジェクトに保存します。
- シートごとに **Global worksheet** / **Normal sheet** を明確に分けています。Globalは全サンプル共通の軸・ゲートを使い、1枚に選択中の1サンプルだけを表示します。サンプル切替は左サイドバーだけで行い、各プロットのヘッダーには現在のGlobalサンプルを表示します。Normalは各カードに具体的なサンプルを固定でき、1枚に複数サンプルの複数分画を並べて比較できます。
- NormalからGlobalへ戻すときは確認画面を表示します。Globalへ変更すると、カードごとのサンプル指定は選択中の1サンプルに統一されます。
- カード左上のチェックで一括操作対象を複数選択します。プロットの右クリックメニュー「軸・表示分画を変更…」で、変更するX軸・Y軸・細胞集団を一画面で選べます。選択中のプロットを右クリックすると選択群が対象になり、選択外のプロットを右クリックするとその1枚だけが対象になります。「表示分画」はプロットに描く細胞集団を変更し、軸が異なるプロットにも適用できます。ゲートの線は分画選択とは独立しており、プロットの◇ボタンまたは右クリックの「ゲート輪郭」で表示・非表示を選びます。表示中の集団に関係なく軸が一致したゲートを描画できます。「解析操作」メニューにはFSC/SSC定型展開、Comp定型解析、Normal sheetの選択項目展開があります。
- Global worksheetの全カードは選択中サンプルに追従し、サンプルを切り替えても軸・配置は変わりません。Normal sheetではカードごとのサンプルと分画パスを保持します。Normal sheetではプロットとPopulation statistics・Compensationウィジェットのチェックを組み合わせて選択し、他サンプルへ一括展開できます。展開方向は横・縦から選び、選択項目間の相対位置を維持します。プロットまたはウィジェットの右クリックからも同じ操作を起動できます。自動表示範囲はGlobalでは最初のサンプル、Normalでは同じ分画・形式・変換のカード群の共通範囲に固定され、手動範囲が優先されます。
- カードのサンプルを固定すると、別サンプルに切り替えてもそのカードは変わりません。同じシートに複数サンプルを並べて比較できます。
- 左の集団をダブルクリック、またはシートへドラッグすると、その集団のプロットが増えます。クリックだけでは全プロットの表示集団は変わりません。
- サンプル欄は「取り込み順」「名前順」で並び替えられ、行をポインターでドラッグするか↑↓ボタンで手動順にできます。移動先の上下に挿入位置が表示されます。サンプル行にフォーカスした状態で↑↓キーを押すと隣のサンプルへ移動します。順序はプロジェクトに保存されます。
- 対応する集団やチャンネルがない場合は、カードにエラーを表示します。別の集団へ自動で置き換えることはしません。

## 軸・ゲート

- **グラフ下のX軸名・左のY軸名をクリック**すると、検索付きチャンネル一覧が開きます。蛍光・マーカー名を入力して絞り込み、↑↓とEnterでも選べます。Escまたは外側クリックで閉じます。
- **軸名を右クリック、または隣の「T」**でスケール詳細を開きます。キーボードでは軸名にフォーカスしてShift+F10。上部の「解析設定」からも同じ画面を開けます。
- Linear / Log / Biexponential (Logicle)、W/T/M/A、最小値・最大値を設定します。範囲は表示座標（Logicleでは変換後の値）です。「データに合わせて自動調整」で自動範囲に戻します。入力は「適用して閉じる」まで反映されず、キャンセル・Escで破棄します。適用先はこの軸のみ／現在のシートの同名チャンネルから選べます。一括適用もUndo一回で戻せます。
- スケール詳細には変更後のヒストグラムをプレビューします。Linearの目盛は通常の数値、Log / Biexponentialの主要目盛は10のべき乗で、各decadeに補助目盛も表示します。
- カード右上の **⇄** でX/Y軸を入れ替え、**⛶** で1プロットを拡大して編集します。Escで元のワークシートへ戻ります。拡大は表示だけを変え、保存する位置・サイズには影響しません。
- Dot、Pseudocolor、Density、Contour、Zebra、Histogram、CDFの7形式。⚙で点の大きさ・透明度・色、平滑化、等高線間隔、外れ点、ビン数、ヒストグラム正規化を調整します。図の背景は白で、格子線はありません。
- Histogram/CDFは「範囲」でX方向にドラッグしてrange gateを作成できます。2次元では矩形・多角形・楕円・四分割を使えます。
- 「選択 / 編集」でゲート内部をダブルクリックすると、元の親プロットを位置固定したまま子分画を新しいプロットとして追加します。↑で子カードから親へ戻ります。ゲート内部の右クリックでは別プロットで開く・名前変更・削除・統計CSVを選べます。削除と名前変更はUndo対応です。
- プロット余白の右クリックから表示設定、複製、単独PDF/SVG保存ができます。
- ワークシート上部の「個別適用 / 全体適用」で、新しく作る分画の範囲を選べます。既定は全体適用です。個別適用は選択サンプルだけ、全体適用は全サンプルで同じチャンネル・座標を評価します。既存ゲートはGate editorの「適用範囲」または分画の右クリックメニューで切り替えられます。全体適用の子はAll eventsまたは全体適用ゲートの下に作成します。ツリーの「すべて / Global / 個別」で分画階層を絞り込みます。
- 矩形はドラッグ、多角形はクリックで頂点を置きダブルクリックで確定、四分割は分割点をクリックします。**新しいゲートの親は、そのカードが表示中の集団です。**
- 「定型展開」は、FSC-A vs SSC-A、FSC-H vs FSC-A、SSC-H vs SSC-Aを現在の集団に一括追加します。FCSに該当するA/Hチャンネルがない場合は追加しません。
- 「選択 / 編集」で既存ゲートの線をドラッグして移動、白いハンドルをドラッグして形を変更します。四分割の中心を動かすと4集団をまとめて更新します。
- 「＋ ウィジェット」からPopulation statisticsとCompensation調整を追加できます。Compensationウィジェットはワークシート上のプロットを見ながら補償行列を編集でき、表示する蛍光チャンネルを個別にオン／オフできます。非表示チャンネルの行列値は保持されます。「Comp定型解析」で選んだY軸チャンネルだけを表示するCompensationウィジェットも自動配置されます。適用先サンプルをチェックボックスで選べ、DIVA補償プリセットも同じチェック対象へ適用できます。Population statisticsはワークシート上の移動・サイズ変更可能なウィジェットです。分画名・色はウィジェットから編集でき、右上の⚙から表示する細胞集団、Events、割合、チャンネル別MFI列を設定できます。集団は初期状態ですべて表示され、非表示設定はワークシートPDFにも反映されます。散布図の点色はゲート削除後も、残っている最も深い子集団の色を優先します。ワークシートPDFと全サンプルレポートにはウィジェットを含めて出力します。軸・Gate editor・補正の詳細は上部の「解析設定」から開きます。変換を変更しても既存ゲートは作成時の変換で評価されます。編集するときは「親集団で編集」でそのゲートの軸を開いてください。
- Normal sheetのPopulation statisticsはウィジェットごとにサンプルを選べます。ウィジェットを右クリックして「Normal: この統計を他サンプルへ展開」を選ぶと、表示項目を保ったウィジェットをチェックしたサンプルへ追加します。
- 表示範囲外のイベントはプロットの端に点として表示します。ゲートを端まで伸ばすと、その端に寄せられた範囲外イベントも含みます。
- **Ctrl+Z / Ctrl+Y**でゲート・軸・配置などを戻せます。履歴は直近40操作で、保存ファイルには含めません。
- 「ゲート階層コピー」は個別ゲートの階層を他サンプルへコピーします。Globalゲートは既に全サンプルへ適用されているため、同ボタンは適用済みであることを確認する操作になります。Normal sheetの「分画を他サンプルへ展開」はプロットカードをサンプルごとに増やす処理です。

## 計算と補正

Rは常駐し、直近2サンプルの元データ・補正後データと計算結果を再利用します。ゲート変更時にRを起動し直しません。連続操作は最新状態にまとめ、古い結果で画面を上書きしません。計算中もプロット追加・軸変更・ゲート編集などを続けられます。黄色い点とステータス欄で再計算中を示します。

散布図は最大12,000イベントを決定的に抽出して描画します。統計・ゲート判定・ヒストグラムには全イベントを使います。補正は元フレームから計算し、負の値を保持します。Compensationはワークシート上のウィジェットで編集します。行がsource、列が測定検出器、単位は%。サンプルごとに補正ON/OFFを設定し、適用先を明示して行列を反映します。無効な行列の場合はエラーを表示し、Undoで戻せます。

## 保存・PDF・CSV

「統計 CSV」は全サンプルの全イベントに基づく細胞数、% parent、% total、各チャンネルmedian、補正状態をUTF-8 BOM付きCSVに保存します。ゲート右クリックからは対象サンプルだけ出力できます。負値は数値として保持します。

単独図はPDF/SVGのベクター形式で保存できます。日本語PDFはWindowsのYu Gothicを使用します。Densityはビンに基づく描画です。BiexponentialはflowCoreのLogicle変換で、FlowJo固有のBiex変換との数値一致を保証するものではありません。Logでゼロ・負値になったイベントも点描画では軸端に表示します。元イベントは削除しません。

「保存」またはCtrl+Sで全ワークシート・ゲート・補正・ノートをJSON保存します。元FCSは埋め込みません。元ファイルの場所とMD5を保持するので、移動・変更せず保管してください。0.2.0プロジェクトは初回にワークシートへ移行します。

- **Worksheet PDF**: ワークシートの青いA4枠が印刷範囲です。「＋ A4ページ」で複数ページを追加し、枠の見出しをドラッグして位置を変えます。左上の↻をクリックすると縦・横が切り替わり、右下をドラッグすると印刷範囲を拡大・縮小できます。枠の大きさに合わせて内容をA4 PDFへ配置します。点線の余白より内側に完全に収まるプロット・統計ウィジェットを印刷し、枠外の項目数は出力後に通知します。印刷枠の配置・向き・拡大率はプロジェクトとテンプレートに保存されます。各プロットの⚙で分画名・割合・X軸の表示を切り替えられます。
- **全サンプル report**: 現在のシートのGlobalプロットを各サンプルへ適用し、固定プロットも収録します。出力時にプロット、集団統計、Compensation / spillover行列を個別に選択できます。対応集団がないサンプルがある場合はエラーになるため、事前にゲートコピーまたは表示集団を調整してください。
- **テンプレート**: 現在のワークシートの配置・軸・表示設定とゲート定義だけを flowdesk-worksheet-template/1 JSONとして保存します。イベントやFCS本体は含みません。左サイドバーは上部ボタンで表示・非表示を切り替えられます。

## 現時点の範囲

FlowJoの全機能・ファイル互換を実装した製品ではありません。FACSDiva実験XMLと対応FCSから、選択したワークシートの対応ゲート（矩形・多角形・楕円・範囲）、プロット配置、軸設定、補償設定を取り込みます。DIVAゲートの4096段階座標とゲート作成時のbiexponential幅を補正して読み込みます。DIVAの全表示要素・ゲート種類や全バージョンとの互換は保証しておらず、指定サンプルでの検証に基づく対応です。FlowJo .wsp読込は未対応です。ヒストグラムの重ね描き、Boolean gate、自動単染色補正は未実装です。

大量サンプル・百万イベント級の応答速度、Windows 10の実機動作は未検証です。キャッシュは2サンプル単位の上限で、使用メモリをバイト数で制限するものではありません。インタラクティブ解析ではファイルのサイズ・更新時刻・変更時刻でキャッシュを無効化し、必要時にMD5を再検証します。プロジェクトを開くときはMD5を検証します。

## 開発

`npm run build` / `npm test` / `npx playwright test`。Windowsビルドは `scripts/build-rtools.ps1`、配布ZIPは `scripts/package-portable.ps1`。R回帰テストは `src-tauri/runtime/R/bin/Rscript.exe --vanilla r/tests.R`。

`scripts/test-ui.mjs` はローカル開発テスト専用のR接続です。productionビルドには含まれません。実EXEの検証は `scripts/native-040-smoke.mjs`。設計は `docs/ARCHITECTURE.md`、検証は `docs/VALIDATION-0.4.0.md` を参照してください。

同梱R・パッケージ・WebView2のライセンスは `runtime/THIRD-PARTY-NOTICES.md`、Rの対応ソースは `runtime/sources/` に含みます。固定WebView2は自動更新されず、新しいアプリ配布時に更新します。UNC/ネットワーク共有からの実行は対応しません。

## AI操作（MCP）

CodexにFlowDesk MCPを登録済みです。FCS取り込み、ワークシート・ゲート・補償編集、統計解析、CSV/PDF/SVG出力に対応します。GUIとは独立したセッションで、JSON保存・読込で受け渡します。詳細は [MCP操作ガイド](docs/MCP.md) を参照してください。
