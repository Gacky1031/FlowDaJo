# FlowDaJo 0.4.3

Windows x64版です。R/flowCoreと固定版WebView2を同梱しています。

## 改善点

- Population statisticsウィジェットの文字サイズを調整できるようにしました。印刷時も設定した大きさで表示します。
- 統計ウィジェットで分画の親子・兄弟関係を見分けやすくしました。
- 四分割ゲートは一つの色を共有します。色の変更は四分割全体に反映され、いずれかを削除すると四分割全体が削除されます。
- 重なったプロットを印刷するとき、ワークシート上の重なり順を保ち、選択中のプロットを最前面に表示します。

## ダウンロード

- `FlowDaJo-0.4.3-windows-x64-setup.exe`: Windowsインストーラー
- `FlowDaJo-0.4.3-windows-x64-portable.zip`: 展開して使うポータブル版
- `SHA256SUMS-0.4.3.txt`: ダウンロードファイルのSHA-256

macOS版はこのリリースには含まれません。
