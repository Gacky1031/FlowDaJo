# FlowDaJo 0.4.6

## 2026-10-05 更新：同じバージョンで差し替え

- 配布用ファイルを `release/0.4.6/` に集約しました。ポータブル版の展開作業は `artifacts/packaging/`、過去版は `artifacts/archive/` に分けています。WindowsとMac実機のビルドスクリプトも配布先を統一しました。
- 上部の「ファイル」「出力」メニューの幅・文字サイズ・行間を統一しました。Popoverに対応しないWebKitでもメニューを開けるようにしました。
- 分画をドラッグして配置するプロットの初期軸を、ファイル内のチャンネル順に依存せずFSC-A／SSC-Aへ変更しました。取り込み済みの軸スケールを引き継ぎます。
- バージョン番号は0.4.6のままです。インストーラー・ポータブルZIP・SHA-256一覧を更新しています。

## 0.4.6で追加した機能

- Normal worksheetでHistogramをドラッグして重ね合わせ、サンプル・分画を比較できます。複数選択の右クリックメニューからも重ね合わせられます。
- Histogramの平滑化をオン／オフでき、縦軸をCount・% of events・%max・Modalから選べます。
- どちら側の曲線でもControlを指定でき、他サンプルへの展開ではControlを固定します。曲線ごとの色のOverrideにも対応しました。
- 比較用の凡例をグラフ外へ移動しました。ワークシート、印刷プレビュー、PDF/SVGに反映します。
- 軸のスケール詳細に「取り込み時の設定へ戻す」を追加しました。元のスケール・範囲・Logicle設定をプレビューし、確認してから適用できます。保存・テンプレート・Undoにも対応します。
- 閉じた軸設定画面から不要な計算を送らないよう改善しました。

Windowsインストーラーとポータブル版は、R・flowCore・WebView2を同梱しています。通常はsetup.exeを、インストールせず利用する場合はportable.zipを展開してFlowDaJo.exeを起動してください。

macOS GitHub Actionsによるインストーラー生成は終了しました。このReleaseはWindows版のみです。
