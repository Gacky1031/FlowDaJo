# FlowDaJo 0.4.7

## 2026-11-06 更新：タイトル・目盛りの表示切り替え

- プロットの⚙「表示設定」に「タイトル・目盛り」を追加しました。プロットのタイトル、X軸のタイトル、Y軸のタイトル、軸の目盛り（Tick）を個別に表示・非表示にできます。ワークシート、PDF、SVG、クリップボードコピーに反映します。既定はすべて表示です。
- バージョン番号は0.4.7のままです。Windowsインストーラー、ポータブルZIP、SHA-256一覧を差し替えています。

## 追加・変更

- プロットの右クリックメニューに「このプロットをクリップボードにコピー」を追加しました。右クリックしたプロット1枚だけを、散布図・ゲート枠・分画ラベル・軸名を含むPNG画像としてコピーします。
- プロットの⚙「表示設定」に「ゲートの枠を黒で表示」「分画名・割合を黒で表示」を追加しました。枠と文字を別々に切り替えられ、ワークシート、PDF、SVGに反映します。既定はオフで、ゲート自体の色は変わりません。
- 上部ツールバーの取り込み操作を「ファイル」メニューへ整理し、印刷範囲での部分表示などのレイアウト調整を含みます。

Windowsインストーラーとポータブル版は、R・flowCore・WebView2を同梱しています。通常はsetup.exeを、インストールせず利用する場合はportable.zipを展開してFlowDaJo.exeを起動してください。

このReleaseはWindows版のみです。
