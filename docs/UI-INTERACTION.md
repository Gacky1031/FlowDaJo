# FlowDesk 0.3.1 UI設計

## 操作方針

グラフの軸・集団・ゲートから直接操作を始める。離れた設定欄へ移動する操作を減らし、右パネルは現在の状態と補正・ゲート編集を表示する。頻繁な操作を短くし、数値の詳細設定は必要なときに開く。

参考にしたFlowJo公式文書:

- [The Graph Window](https://flowjo.com/docs/flowjo10/graphs-and-gating/gw-overview): 軸ごとのパラメータ選択と変換への入口。
- [T Button](https://flowjo.com/docs/flowjo10/graphs-and-gating/gw-transform-overview/gw-tbutton): グラフに隣接する変換操作。
- [Graph Window Menus](https://www.flowjo.com/docs/flowjo10/graphs-and-gating/gw-overview/gw-menus): グラフ上の操作とキーボード操作。

これらを操作設計の参考にしており、FlowJoと同一の変換方式・ファイル互換・全機能を保証するものではない。

## 0.3.1で実装した操作

| 場所 | 操作 | 結果 |
| --- | --- | --- |
| X/Y軸名 | 左クリック | 検索付きチャンネル一覧。選択中のチャンネルにチェック |
| 一覧 | 文字入力、↑↓、Enter | 蛍光名・マーカー名で絞り込み、選択 |
| 軸名 | 右クリック、Shift+F10 | 該当軸だけのスケール詳細 |
| 軸隣のT / 右パネルの詳細 | クリック | 同じスケール詳細。右クリックを知らなくてもアクセス可能 |
| スケール詳細 | 適用先を選択 | 1軸／シート内の同じチャンネルに反映。HistogramのCount軸は除外 |
| スケール詳細 | キャンセル / Esc | 編集前の設定を維持 |
| カード上端の⇄ | クリック | X/Yのチャンネル・変換・範囲をまとめて入替 |
| カード上端の⛶ | クリック | 1グラフを拡大してゲート・軸を編集 |
| 拡大表示 | Esc | 保存レイアウトを変えずにワークシートに戻る |

## 操作ミスを防ぐ設計

- 詳細画面はドラフト編集。適用時にLogicleパラメータと範囲を検証し、入力欄の近くに理由を表示。
- ダイアログ表示中は背後のゲート削除やUndoショートカットを実行しない。
- 軸ラベル上のクリックからゲートを作らない。
- チャンネル・範囲・表示集団の切替中に、古いグラフと新しいラベルを組み合わせて表示しない。
- 複製プロットは既存カードに重ならない右側へ配置。選択カードは手前に表示。
- Y軸がCountのHistogramでは蛍光選択とX/Y入替を無効化。
- 一括適用でも1回のUndoで復元。保存形式は既存の軸・ワークシート形式を継続。

## 残る改善候補

大規模なUI変更を行う前に、実際の解析データと操作時間で優先順位を検証する。

1. 蛍光の実測値での目盛表示。現在のLogicle目盛と手動範囲は変換後座標。
2. グループへのゲート適用・バックゲーティング・複数サンプルの同時比較を短い操作で行う。
3. ヒストグラムの描画・平滑化とFlowJoとの違いを実データで検証。
4. WindowsとmacOSの実機で生成済みPDFの埋め込み表示と印刷を確認する。
5. FlowJo WSP、DIVAゲートの完全な読み込みと移行検証。


## 0.4.0 の追加操作

- 選択ツールでゲート内部をダブルクリック: 親カードを固定したまま、その子分画のプロットを追加。↑: 親集団。
- ゲート内部/左ツリーの右クリック: drill down、新しいカード、名前変更、CSV、子孫を含む削除。ゲート内部のダブルクリックは親カードを残して子カードを追加する。
- プロット余白の右クリック: 表示設定、拡大、軸交換、PDF/SVG、複製、削除。
- 軸名のクリックは蛍光選択、右クリック/TはLinear・Log・Logicleと範囲設定。
- ⚙: 7形式、点径0.5–8px、透明度、色、密度平滑化、外れ点、等高線5/10/20%、ビン数、ヒストグラム正規化。
- Histogramの縦軸名をクリック／右クリックするとCount・% of events・% Max・Modalと平滑化のオン／オフを選べる。Normalでは同じX軸チャンネルのHistogramをヘッダーから重ねてドロップするか、複数選択して右クリック「選択ヒストグラムを重ね合わせる」で比較する。重ね合わせ先の軸・ビン・平滑化・正規化に統一する。「比較」で曲線ごとのサンプル・分画・色のOverrideとControlを設定でき、他サンプルへの展開ではControlの曲線だけを固定する。Globalへ切り替える際は確認後に重ね合わせとControl指定を解除する。
- Histogram/CDFでは範囲ゲート、2次元では矩形・多角形・楕円・四分割。線/ハンドルで編集。
- 統計CSVは全イベントを集計。散布点表示は最大12,000、密度集計は全イベント。
- 「個別適用 / 全体適用」は新規ゲートの適用範囲を決める。Gate editorで既存ゲートも変更でき、全体適用ゲートは全サンプルのツリーと統計に現れる。
- ゲート内部のダブルクリックは、元カードを元の位置に残したまま子分画を新規カードとして追加する。定型展開はA/Hチャンネルが揃ったFSC-A/SSC-A系の3カードを一括作成する。

- 「＋ ウィジェット」からPopulation statisticsとCompensation調整パネルをワークシートへ追加できる。Compensationパネルでは表示する蛍光チャンネルをチェックで切り替え、行列編集後にチェックしたサンプルへ適用できる。「Comp定型解析」は選択したY軸蛍光だけを表示するCompensationパネルも自動配置する。ワークシート削除はシートタブの右クリックメニューから行う。
- Global worksheetは常に選択サンプル1つだけを全カードへ表示する。サンプル選択は左サイドバーに一本化し、プロットヘッダーは現在のサンプルを表示するだけで個別バインドはできない。Normal sheetはカードごとにサンプルを固定する。
- Global worksheetとNormal sheetは別の作業モデルとしてシート単位で保持する。Globalは全カードをactive sampleへ追従させて1サンプルだけを表示し、Normalは全カードを具体的なサンプルへ固定して複数サンプル・複数分画を並べる。
- 左サイドバーの分画名はワークシートへドラッグしてその場にプロットを追加できる。プロットを右クリックするとX軸、Y軸、表示分画の個別変更と、軸・分画のまとめ変更を起動できる。選択中のプロットを右クリックすると選択群が対象になり、選択外ならその1枚だけが対象になる。「表示分画」はプロットに描く細胞集団を切り替える操作で、ゲートを作成した軸とは無関係に適用する。ゲートの線は別の「ゲート輪郭」で選び、軸が合うプロットに描画する。「グリッド整列」は最寄りの位置へ揃え、隣のドロップダウンで行×列を指定してシート全体または選択カードを配置する。Normal sheetには「解析操作」内に「Normal 分画を他サンプルへ展開」があり、選択したサンプルAの分画プロットをB/Cへ複製する。カードを1枚だけ展開する場合はプロットの右クリックメニューから起動できる。
- 複数選択したプロットとウィジェットは「位置揃え」から左端・横中央・右端・上端・縦中央・下端を揃えられる。各カードのチェックボックスでプロットと統計／補償ウィジェットを混ぜて選択できる。
- ワークシートの空白部分をドラッグすると、矩形に触れたプロットと統計／補償ウィジェットを複数選択できる。Shift/Ctrl/⌘を押しながらドラッグすると現在の選択へ追加する。
- 分画ツリーのすべて/Global/個別フィルタで、全サンプル共通の分画とサンプル固有の分画を切り替えて表示する。分画の右クリックメニューからGlobal⇄個別の移動を行える。
- Population statisticsはGlobalでは選択サンプルに追従し、Normalでは各ウィジェット上部のサンプル選択で別々に固定できる。Normalではプロット・統計・Compensationウィジェットのチェックを混在選択し、右クリックまたは解析操作から、相対配置を保ったまま他サンプルへ横方向・縦方向に展開できる。Compensationの展開先はコピー先サンプルだけを適用先として選択する。
- ファイルメニューの「テンプレートを保存／適用」で、現在のシートに必要なゲート・配置・印刷枠を別の実験へ移せる。適用時にサンプルと検出器を対応付け、不足や衝突は表示して中止する。イベントデータは含まない。
- A4印刷枠は解析中は薄い境界だけを表示し、「印刷枠を編集」でハンドルを有効にする。見出しドラッグで移動、左上の↻で縦横切替、右下で拡大・縮小できる。「＋ A4ページ」でページを追加する。全サンプルreportのチェック項目は詳細付録を選び、配置済みウィジェットは各サンプルページへ印刷する。デスクトップのプレビューにはRが生成した実PDFを表示し、その同じバイト列を保存する。
- 上部のファイル／出力メニューで保存・テンプレート・PDF/CSVをまとめる。左欄のサンプル名検索、ワークシートの「全体」「選択」ズームを使える。サンプルの並び順は取り込み順・名前順・手動を選び、手動では行をドラッグして並べ替える。
- ステータス欄は保存先と未保存状態を表示する。未保存の変更はアプリ内の復旧用スナップショットへ記録し、次回起動時に復旧するか選べる。明示保存に成功した時点で復旧用データを消す。
- 分画名検索は一致する分画とその祖先を残し、選択集団のパンくずとGlobal／個別バッジを表示する。コンペ行列のセルへフォーカスすると同じサンプル・軸対のプロットを強調し、プロット選択からも対応セルを強調する。未適用の変更セルは別色で示す。

- Global worksheetでは最初に取得した表示範囲を軸ごとに保持し、サンプルを切り替えても同じ軸で比較する。Normal sheetでは同じ分画・表示形式・変換のカード群について自動範囲の最小〜最大を共有し、展開したカードにも同じ範囲を継承する。手動で指定した最小値・最大値は優先される。
