# FlowDaJo 0.4.4

Windows x64版です。R/flowCoreとWebView2を同梱しています。

## 改善点

- 分画名と割合のラベルをプロット上でドラッグして移動できます。ラベル位置は保存され、Undo・やり直しやテンプレートにも反映されます。
- プロット表示設定からラベル文字サイズを6〜24 ptに調整できます。設定はワークシートとPDFに反映されます。
- 四分割ゲートを含む各種ゲートの割合ラベルを移動できます。ラベル位置を既定値に戻す操作も追加しました。
- 0.4.3までのPopulation statistics文字サイズ、ゲート階層表示、四分割ゲートの色・削除、重なったプロットの印刷順の改善を含みます。

## ダウンロード

- `FlowDaJo-0.4.4-windows-x64-setup.exe`: Windowsインストーラー
- `FlowDaJo-0.4.4-windows-x64-portable.zip`: 展開して使うポータブル版
- `SHA256SUMS-0.4.4.txt`: 配布ファイルのSHA-256

macOS版はこのリリースには含まれません。
