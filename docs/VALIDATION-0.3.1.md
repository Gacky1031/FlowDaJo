# 0.3.1 軸UI検証

対象: Windows x64、Rust/Tauri、同梱R/flowCore。R解析アルゴリズムは0.3.0から変更なし。

## UI自動テスト

`npx playwright test`:

- 既存ワークシート: 7プロット、矩形ゲート編集とUndo、軸変更、計算中の連続操作、固定サンプル、保存復元。
- 既存ゲート: 多角形頂点、四分割一括移動、カード移動・サイズ変更、サンプル間ゲートコピー。
- 軸UI: 検索、一致なし、Enter選択、フォーカス復帰、右クリック、Shift+F10、無効なLogicle・範囲の拒否、キャンセル、同じチャンネル3軸への一括適用、Undo、X/Y入替、拡大と復帰、HistogramのCount軸。
- 幅1100px: 右パネルなしでY軸選択・スケール変更・保存復元。詳細画面が表示範囲内に収まる。

`npm test` は既存Rプロトコル・ワークシート・非同期ジョブの回帰テスト。

## 実EXE

`node scripts/native-axis-smoke.mjs` は配布フォルダの実EXEを起動し、同梱Rの使用、デモ解析、軸選択、右クリック詳細、値の再表示、拡大と復帰を確認する。テスト用に起動したプロセスだけを終了する。結果は `artifacts/native-axis-0.3.1-validation.json`。

## 制約

0.3.0の解析・配布上の制約を継続。Windows 10 / クリーンVMでの検証、百万イベント級の性能、FlowJo全機能との互換は未検証。UI改善によってこれらの保証が追加されたわけではない。

## 実行結果（2026-09-16）

npm run build: 成功。UI 4シナリオ成功、最終調整後の軸UI 2シナリオも再確認成功。npm test: 5件成功。実EXE: 同梱R、16,000イベントのデモ、FITC-A選択、右クリック詳細、W=0.7の反映、拡大からの復帰を確認し、ページエラー0件。
