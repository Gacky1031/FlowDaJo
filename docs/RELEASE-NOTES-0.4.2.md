# FlowDaJo 0.4.2

Windows x64版です。R/flowCoreと固定版WebView2を同梱しています。

## 改善点

- 印刷レポートの蛍光チャンネル表示に、FCSに記録された抗体名を追加しました。プロット軸、MFI欄、Compensation行列で確認できます。
- サンプル欄の名前を折り返して表示し、境界をドラッグして欄の幅を調整できるようにしました。幅は次回起動時にも保持されます。
- 「ファイル」メニューから解析をリセットして、新しい解析を始められるようにしました。
- ゲート階層を右クリックから切り取り／コピーし、別の親分画の下へ貼り付けられるようにしました。
- サンプル欄とPopulation statisticsでゲートを複数選択し、右クリックまたはDeleteキーでまとめて削除できます。
- プロットを右クリックして削除できます。複数選択中は選択したプロットをまとめて削除します。

## ダウンロード

- `FlowDaJo-0.4.2-windows-x64-setup.exe`: Windowsインストーラー
- `FlowDaJo-0.4.2-windows-x64-portable.zip`: 展開して使うポータブル版
- `SHA256SUMS-0.4.2.txt`: ダウンロードファイルのSHA-256

macOS版はこのリリースには含まれません。
